# Бетті тану жүйесі (Flask + OpenCV)

Бетті анықтау — OpenCV YuNet, бетті сәйкестендіру — OpenCV SFace (128 өлшемді вектор, косинустық ұқсастық, шегі 0.363).
Басты бетті (тану) кез келген адам қолдана алады. Тіркеу мен жою — тек құпия сөзі бар әкімшіге.

## Деплой (GitHub + Render + Neon, бәрі тегін)

**1. GitHub.** Жаңа репозиторий ашып, осы папканың мазмұнын жүктеңіз:
```
git init
git add .
git commit -m "Бетті тану жүйесі"
git branch -M main
git remote add origin https://github.com/<аты>/<репо>.git
git push -u origin main
```

**2. Дерекқор (Neon).** https://neon.tech сайтында тіркеліп, жоба ашыңыз да, `Connection string` (postgresql://... түрінде) көшіріп алыңыз.
Тегін хостингтердің файл жүйесі әр деплойда тазаланады, сондықтан деректер сыртқы базада сақталады.

**3. Сайт (Render).** https://render.com → New → Blueprint → GitHub репозиторийіңізді таңдаңыз (`render.yaml` автоматты оқылады).
Сұралғанда екі мән енгізіңіз:
- `DATABASE_URL` — Neon-нан көшірген жол;
- `ADMIN_PASSWORD` — өзіңіз ойлаған күшті құпия сөз.

Деплой біткен соң `https://<аты>.onrender.com` сілтемесін кез келген адамға жібере аласыз. HTTPS автоматты қосылады, сондықтан камера жұмыс істейді.

**4. Қолдану.** `/login` бетінде құпия сөзбен кіріп, «Жаңа адамды тіркеу» арқылы адамдарды қосыңыз. Содан кейін сілтемені бөлісіңіз.

Ескертулер:
- Тегін Render 15 минут әрекетсіздіктен кейін ұйықтайды, бірінші ашылу ~30–60 секунд алады.
- Модельдер деплой кезінде (`download_models.py`) жүктеледі.
- Railway/Heroku үшін `Procfile` дайын, айнымалылар сол: `DATABASE_URL`, `ADMIN_PASSWORD`, `SECRET_KEY`.

## Жергілікті іске қосу
```
python -m venv venv
venv\Scripts\activate          (Linux: source venv/bin/activate)
pip install -r requirements.txt
set ADMIN_PASSWORD=1234        (Linux: export ADMIN_PASSWORD=1234)
python app.py
```
`http://127.0.0.1:5000` — жергілікті режимде SQLite қолданылады.

## Жиі қателер
- **Камераға рұқсат жоқ** — мекенжай жолындағы құлып белгішесінен камераны рұқсат етіп, бетті жаңартыңыз. Сайт тек HTTPS-те (немесе localhost-та) камера ашады.
- **Тіркеуде «Қате пайда болды»** — Render логын қараңыз; көбіне `DATABASE_URL` қате немесе модельдер жүктелмеген.
- **Адам танылмайды** — тіркеу фотосы анық, бет тура қараған, жарық жақсы болсын.
- **Құпия сөз қабылданбайды** — Render → Environment бөлімінде `ADMIN_PASSWORD` бар ма, тексеріңіз.

## Құпиялылық
Адамдардың фотосы мен бет векторларын тек олардың келісімімен сақтаңыз. Жазбаны әкімші бетінен кез келген уақытта жоюға болады.
